# 0.5.15 — 2026-09-04

## Changed

- **An upstream Hacker News 500 now retries before the call fails**, where it previously failed on the first attempt — `@cyanheads/mcp-ts-core` 0.12.4 moved 500 into the transient retry set.
- **A caller that disconnects mid-call is now reported as a cancellation** rather than an internal server error.
- Shipped skills: `add-tool` 2.21, `api-config` 1.15, `api-context` 2.2, `api-errors` 1.8, `api-linter` 1.13, `api-utils` 2.8, `design-mcp-server` 2.23, `maintenance` 2.6, `release-and-publish` 2.13, `setup` 1.10.

## Fixed

- **`HnService.fetchItems` rethrows a caller cancellation** instead of absorbing it as a per-item failure — a batch item fetch now stops when the caller cancels, instead of spending the rest of the id list on fetches nobody is waiting for.

## Security

- **`fast-uri` and `qs` pinned via a new `overrides` block** to `^3.1.6` and `^6.16.0` — clears 6 advisories `bun audit` reported through the framework's MCP SDK dependency (4 high in `fast-uri@3.1.5`: SSRF and host confusion; 2 moderate in `qs@6.15.3`). `bun audit` now reports no vulnerabilities across 372 packages.
